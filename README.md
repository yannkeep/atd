# Quartiers de dignité

Fan-club éditorial, indépendant et non officiel d’ATD Quart Monde.

Le site célèbre une méthode : agir avec les personnes confrontées à la pauvreté, reconnaître leur savoir, défendre les droits fondamentaux et refuser que quiconque soit laissé de côté.

## Une frontière claire

Ce projet n’est ni créé, ni validé, ni mandaté par ATD Quart Monde. Il ne reprend pas son logo, ne collecte aucun don et renvoie vers les sites officiels pour les informations, l’engagement et le soutien financier.

## Mise en ligne

Le site est volontairement statique : `index.html`, `styles.css` et `app.js`, sans générateur ni étape de compilation. Dans les réglages GitHub Pages du dépôt, choisir **Deploy from a branch**, puis la branche `main` et le dossier racine `/`.
